# 🚆 AI Rail Disruption Copilot

An AI-powered system designed to assist in **real-time rail disruption management**, helping optimize decisions during delays, rerouting, and operational challenges.

🌐 Live Demo: https://ai-rail-disruption-copilot.vercel.app

---

## 📌 Overview

The **AI Rail Disruption Copilot** is built to simulate and support decision-making in complex railway scenarios. It focuses on handling disruptions intelligently by analyzing inputs and suggesting actionable strategies.

This project explores how AI can be applied to **large-scale infrastructure systems** with dynamic and uncertain conditions.

---

## 🚀 Features

- 🔍 Intelligent disruption analysis  
- 🚦 Delay and rerouting assistance  
- 📊 Structured input handling for real-world scenarios  
- ⚡ Fast and responsive UI  
- 🧠 AI-driven decision support (extensible)  

---

## 🛠️ Tech Stack

- **Frontend:** TypeScript, HTML, Tailwind CSS  
- **Build Tool:** Vite  
- **Backend / DB:** Supabase  
- **Deployment:** Vercel  

---

## 🧠 How It Works

1. User inputs a disruption scenario  
2. System processes structured data  
3. AI logic analyzes constraints (delays, routes, resources)  
4. Outputs possible actions / decisions
